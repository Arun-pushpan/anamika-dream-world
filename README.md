A dreamy, whimsical, and magical personal web page created with love for **Anamika MG**.

- **Magical Hero Section**: Dreamy pastel gradients, floating sparkles, and animated hearts.
- **Cute Animated Ghost**: Pure CSS floating ghost with ribbon bow and blushing cheeks.

## 🚀 How to Host on GitHub Pages (Free)

Follow these quick steps to host this website live on GitHub:

### Step 1: Create a Repository on GitHub
1. Go to [github.com/new](https://github.com/new).
2. Set the **Repository name** (e.g. `anamika-world` or `anamika-dream-world`).
3. Set the visibility to **Public**.
4. Leave "Add a README file", ".gitignore", and license **unchecked** (we already have them).
5. Click **Create repository**.

### Step 2: Link & Push from Your Terminal
Run the following commands from inside this project directory (`anamika-dream-world`):

```bash
# Add your GitHub repository as remote origin (replace YOUR_USERNAME and REPO_NAME with yours)
git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git

# Push the main branch to GitHub
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (tab at the top) > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and root `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, your site will be live at:
   `https://<YOUR_USERNAME>.github.io/<REPO_NAME>/`

## 💻 Local Preview
To preview this page on your local machine:
- Simply double-click `index.html` to open it directly in your web browser.
- Or run a quick local HTTP server:
  ```bash
  python3 -m http.server 8000
  ```
  and visit `http://localhost:8000` in your browser.
